Babel is an extremely powerful tool for frontend development. Chances are you will find the plugin you need on npm, but what if you need something novel?

Use cases

  • Adding transformations to personal TypeScript/JavaScript libraries
  • Automating test cases or mocks
  • Simple codemods

Learn these terms

  • AST: Source code abstracted as a JavaScript object. When Babel parses code, it transforms it into this.
  • Nodes: These are objects representing specific Babel types in the AST
  • Paths: These are objects that link nodes to one another in the AST
  • Visitor: Visitors allow you to perform operations on specific paths in the AST based on their type

Treat yourself

  • Do yourself a favor and prefer TypeScript to JavaScript when writing your plugin.
  • Type guards (e.g. t.isObjectProperty(path)) in @babel/types create a flawless autocomplete experience and result in more resilient plugins.

Libraries you'll need

  • @babel/core: Parse source code into an AST and transform it. In particular, see the parseAsync() and transformAsync() API references.
  • @babel/types: Check node types and construct new AST nodes.
  • @babel/generator: Generate source code from an AST.
  • @babel/template: Build an AST from strings and placeholders rather than the utility functions in @babel/types.
  • @babel/helper-plugin-utils: Provide clear messages to your plugin users if their Babel version doesn't have APIs required by your plugin.
  • babel-plugin-tester: The easiest way to test your babel plugin.

Resources

  • Babel Plugin Handbook: Go deeper into Babel plugin concepts.
  • Babel Types: Quickly search for the AST node types you're looking for.
  • Babel Plugin Macros: Allow plugin users to utilize your plugin transformations without adding it to their Babel config. This is useful for libraries like create-react-app that don't allow you to customize your plugins.

Finding examples

  • Hiding in plain sight: The best place to find example plugins is the Babel monorepo itself.
  • Less is more: The more basic the plugin, the more fruitful for understanding.
    • @babel/plugin-proposal-export-default-from
    • @babel/plugin-transform-react-constant-elements
    • @babel/plugin-transform-object-assign
    • @babel/plugin-transform-duplicate-keys
